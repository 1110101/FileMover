FileMover automatically sorts your downloads by file type. PDFs, images, videos, archives - everything goes to the right folder automatically.

What Makes FileMover Great

Simple, powerful, and runs completely in the background

Invisible Operation

Runs silently in your system tray. Set it up once, forget about it. Your downloads stay organized 24/7 without any interaction.

Full Control

Auto-move toggle, dry-run mode, manual "Move Now" button, configurable delays. Windows autostart optional. You're in complete control.

Real-Time Detection

Watchdog monitors your folders continuously. The moment a file appears, FileMover knows about it and queues it instantly.

Simple GUI

Clean interface for managing rules. Add source/target folders, specify file types, view queue status, and check activity logs.

Safe & Smart

File lock detection prevents moving files in use. All settings persist in Windows Registry. Automatic crash logging for reliability.

Easy Installation

Download the installer and run it. No Python, no dependencies, no configuration. Just install and it works out of the box.

How to Install & Use

Get up and running in under a minute

1

Download Installer

Easiest way - No Python required!

  • Go to Releases on GitHub
  • Download FileMover-*-Setup.exe (installer) or FileMover.exe (portable)
  • Run the installer - that's it! 🎉
  • Note: Windows SmartScreen may show a warning (not code-signed). Click "More info" → "Run anyway"

Alternative: From Source (Developers)

git clone https://github.com/1110101/FileMover.git
cd FileMover
pip install -r requirements.txt
python move.py
2

Find in System Tray

After installation, FileMover appears in your system tray:

  • Look for the folder icon in the system tray (bottom right)
  • Double-click the icon to open the configuration window
  • Or right-click for quick menu: Open or Quit

If this is your first time, the configuration window opens automatically!

3

Create Your First Rule

Set up downloads folder organization:

  • Source Folder: Your Downloads folder (e.g., C:\Users\YourName\Downloads)
  • Target Folder: Where to move files (e.g., D:\Documents\PDFs)
  • Extensions: File types to move (e.g., .pdf, .jpg, .png)
  • Click "Add Rule" to save

Tip: Create multiple rules for different file types - PDFs, images, videos, archives, etc.

4

Configure Settings & Start

Fine-tune your experience:

  • Wait Time: Set delay (1-60 minutes) before moving files
  • Auto-Move Toggle: Enable/disable automatic moving (🟢/🔴)
  • Autostart: Enable to start with Windows
  • Dry Run: Test mode to preview without moving

Close the window - FileMover keeps running in the background!
